# Site-DAC-2026
# EquipFlow — Website de Apresentação

Link Do Site:

Site desenvolvido para apresentação do projeto **EquipFlow**, um protótipo acadêmico full stack criado no contexto do DAC 2026 do curso de TADS da UCDB.

O objetivo do site é funcionar como uma apresentação interativa do sistema, exibindo:

* visão geral do projeto
* problema identificado
* funcionalidades
* arquitetura da aplicação
* tecnologias utilizadas
* fluxo de funcionamento
* galeria de telas do sistema
* documentação visual para apresentação em banca

---

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript Vanilla

---

## Recursos do Site

* Design tecnológico e minimalista
* Interface responsiva
* Navbar flutuante
* Efeitos visuais modernos
* Modal para visualização das imagens
* Galeria interativa
* Compatível com desktop e mobile
* Estrutura em página única (single page)
